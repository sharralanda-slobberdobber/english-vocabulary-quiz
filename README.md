# 英语词汇小测试 - 一年级版

适合一年级小朋友的英语词汇学习应用，基于Oxford 3000高频词汇表。

## 功能特点

- 📖 **学习模式**：单词卡片展示，包含英文、中文翻译、例句和词性
- 🎯 **测试模式**：四选一选择题，检验学习成果
- 🔊 **发音功能**：点击卡片听单词发音（使用Web Speech API）
- � **语音评分**：录音打分功能，练习发音
- �🎨 **护眼设计**：莫兰迪色系，低对比度低饱和度，对眼睛友好
- 📱 **移动优化**：专为手机屏幕设计，适合iPhone和Android
- ⭐ **进度追踪**：显示学习进度和测试得分
- 🔀 **打乱顺序**：随机排列单词，增加学习趣味性
- 📊 **统计分析**：词汇量估算和各级别掌握情况
- 📈 **增长曲线**：可视化词汇量增长趋势
- 🔄 **艾宾浩斯复习**：基于遗忘曲线的智能复习系统
- 📓 **错题本**：记录错误答案，方便针对性复习

## 难度分级

- **Level 1** (300词)：最核心的高频词汇（A1基础）
- **Level 2** (400词)：基础扩展词汇（A1扩展）
- **Level 3** (500词)：初中级词汇（A2核心）
- **Level 4** (600词)：初中扩展词汇（A2扩展）
- **Level 5** (600词)：中高级词汇（B1核心）
- **Level 6** (547词)：高级扩展词汇（B1扩展）

## 部署到Gitee Pages（国内访问）

### 步骤1：创建Gitee仓库

1. 访问 [Gitee](https://gitee.com/) 并登录/注册账号
2. 点击右上角 "+" → "新建仓库"
3. 填写仓库信息：
   - 仓库名称：`english-vocabulary-quiz`
   - 仓库介绍：`英语词汇小测试 - 一年级版`
   - 是否公开：选择"公开"
   - 初始化仓库：选择"不初始化"
4. 点击"创建仓库"

### 步骤2：上传文件

**方法A：通过Gitee网页界面上传**
1. 进入刚创建的仓库
2. 点击"文件"标签
3. 点击"上传文件"
4. 将以下文件拖拽上传：
   - `index.html`
   - `words.json`
   - `README.md`
5. 点击"提交"

**方法B：通过Git命令上传**
```bash
# 初始化Git仓库
git init

# 添加所有文件
git add .

# 提交更改
git commit -m "Initial commit"

# 添加Gitee远程仓库（替换为你的仓库地址）
git remote add origin https://gitee.com/你的用户名/english-vocabulary-quiz.git

# 推送到Gitee
git push -u origin master
```

### 步骤3：启用Gitee Pages

1. 进入仓库页面
2. 点击右侧的"服务" → "Gitee Pages"
3. 点击"启动"
4. 选择部署分支：`master`
5. 选择部署目录：根目录（默认）
6. 点击"启动"按钮
7. 等待部署完成（通常需要1-2分钟）

### 步骤4：访问应用

部署完成后，你会获得一个访问链接，格式类似：
```
https://你的用户名.gitee.io/english-vocabulary-quiz
```

在浏览器中打开此链接即可使用应用。

### 步骤5：更新应用

如果需要更新应用：
1. 修改本地文件
2. 重新上传到Gitee
3. 在Gitee Pages页面点击"更新"按钮
4. 等待部署完成

## 使用方法

### 在电脑上使用

1. 下载所有文件到本地文件夹
2. 双击 `index.html` 文件
3. 在浏览器中打开即可使用

### 在iPhone/iPad上使用

**方法1：通过GitHub Pages访问**
1. 访问部署后的GitHub Pages链接
2. 在Safari中打开
3. 点击分享按钮 → "添加到主屏幕"
4. 像App一样使用

**方法2：本地文件访问**
1. 将文件保存到iCloud Drive或通过AirDrop发送到iPhone
2. 在"文件"App中找到 `index.html`
3. 点击打开，选择用Safari打开
4. 添加到主屏幕方便使用

### 在Android手机上使用

1. 访问部署后的链接
2. 在Chrome中打开
3. 点击菜单 → "添加到主屏幕"
4. 像App一样使用

## 技术说明

- 纯HTML/CSS/JavaScript实现，无需后端
- 使用Web Speech API提供英语发音
- 使用localStorage存储学习进度
- 响应式设计，适配各种屏幕尺寸

## 浏览器兼容性

- Chrome/Edge：完全支持
- Safari：支持（iOS和macOS）
- Firefox：支持
- 推荐使用最新版本浏览器

## 注意事项

- 发音功能依赖浏览器的语音合成引擎，不同设备和浏览器发音质量可能不同
- 建议在网络环境下使用以获得最佳体验
- 学习进度会保存在本地浏览器中
